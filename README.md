# Kesimpulan Tugas 4, 5, dan 6

## Tugas 4 – Python Data Structures
Pada tugas ini dipelajari berbagai struktur data dalam Python seperti list, tuple, set, dan dictionary. 
Setiap struktur memiliki karakteristik dan fungsi yang berbeda dalam pengolahan data. Selain itu, digunakan juga konsep comprehension untuk mempermudah pembuatan data secara efisien.

## Tugas 5 – Function dan Class
Tugas ini membahas penggunaan function dan class dalam Python. Function digunakan untuk membuat program lebih terstruktur dan dapat digunakan kembali. 
Class digunakan untuk merepresentasikan objek dengan atribut dan method, sehingga mempermudah pengelolaan data secara terorganisir.

## Tugas 6 – NumPy, pandas, dan OOP
Pada tugas ini dipelajari penggunaan library NumPy untuk pengolahan data numerik dan pandas untuk pengolahan data berbentuk tabel.
Selain itu, digunakan juga konsep File I/O untuk menyimpan hasil ke dalam file, serta penerapan OOP melalui class GradeBook untuk mengelola data nilai.

## Kesimpulan
Secara keseluruhan, Python memiliki kemampuan yang sangat fleksibel dalam pengolahan data, baik menggunakan struktur dasar maupun library tambahan. 
Penggunaan function, class, dan library seperti NumPy serta pandas sangat membantu dalam membangun program yang lebih terstruktur, efisien, dan mudah dikembangkan.
